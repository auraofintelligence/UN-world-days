A static browser tool for exploring UN international days in calendar and searchable-list views,
alongside moon phases and `.ics` calendar export.

The interface can also hold custom days for personal use. It is a convenience layer, not an
official United Nations publication or a guaranteed current calendar.

## What is here

- `index.html` contains the calendar, list, search, theme and export interface.
- `assets/` contains the local supporting assets.
- `LICENSE` records the reuse conditions.

## Use locally

Open `index.html` in a browser. No build step or backend is required.

Before relying on a date for public programming, campaigns or reporting, verify it against the
current official UN observance page. Custom entries should be reviewed before sharing an exported
calendar.
